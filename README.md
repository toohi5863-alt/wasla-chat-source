# وصال — المصدر الكامل

يحتوي هذا المستودع على **أرشيف المصدر الكامل المنقّح** للتطبيق، مضغوطًا في ملف واحد حتى تبقى بنية المجلدات كما هي عند التنزيل.

## التنزيل وفك الضغط

1. نزّل [أرشيف المشروع `wasla-chat-source.zip`](./wasla-chat-source.zip).
2. فك ضغطه؛ سينشأ مجلد `wasla-chat-source/` مع شجرة المشروع.
3. افتح المجلد ونفّذ:

   ```bash
   cd wasla-chat-source
   flutter pub get
   flutter analyze
   flutter test
   ```

الإصدار في `pubspec.yaml`: **1.20.31+81**. يتضمن الأرشيف تطبيق Flutter وملفات Android والأصول والتوثيق واختبارات المشروع ووظائف وترحيلات Supabase.

## إعدادات خاصة

أُزيلت مفاتيح الخدمة وكلمات المرور وملفات التوقيع ومخرجات البناء من النسخة العامة. ملف `firebase.env.example.json` قالب توضيحي فقط؛ أضف إعدادات Firebase وSupabase محليًا من مصادرك الموثوقة، وأنشئ مفتاح توقيع Android خاصًا بك عند الحاجة إلى إصدار موقّع. لا تضع أسرارك أو مفاتيح التوقيع في المستودع العام.
